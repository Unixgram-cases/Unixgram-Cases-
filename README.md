# Unixgram Cases

Приложение для открытия кейсов за звёзды Unixgram.

## Возможности

- Регистрация / вход (демо Google + обязательный @username Unixgram)
- Баланс в звёздах
- Пополнение: заявка → отправка звёзд на аккаунт владельца в Unixgram → подтверждение админом
- Кейсы с настраиваемыми предметами и процентами выпадения
- Кейс «Ракеты» и «Стартовый» из коробки
- Админ-панель (пароль):
  - Статистика
  - Подтверждение/отклонение пополнений
  - Создание / редактирование / удаление кейсов и изменение шансов
  - Управление админами (только владелец @gold)
  - Смена пароля

## Запуск

```bash
cd unixgram-cases
npm install
npm start
```

Откройте http://localhost:3000

Админ-панель: http://localhost:3000/admin.html  
Пароль по умолчанию: `admin123` (смените сразу!)

## Переменные окружения (.env)

```
PORT=3000
JWT_SECRET=ваш-секретный-ключ
ADMIN_PASSWORD=новый-пароль
```

## Важно

1. **Google OAuth** сейчас упрощён (ввод email вручную). Для продакшена подключите настоящий Google Sign-In.
2. **Пополнение звёзд**: пользователь создаёт заявку и отправляет звёзды на аккаунт владельца в Unixgram. Админ вручную проверяет перевод по @username и подтверждает. Для автоматизации нужен бот Unixgram, который принимает платежи (send_invoice) и вебхук.
3. **Владелец**: @gold — только он может добавлять/удалять админов и менять пароль.
4. Данные хранятся в `data/*.json`. Для продакшена лучше PostgreSQL/Mongo.
